# Acceptance

Hand-run checks for the suite. Each milestone adds its items. An item is `N. **Title.** Setup: ... Command: ... Expected: ... Covers R.... Rerun when ...`, followed by its run history; an item not yet run says "Not yet run." Runs use scratch profiles (`CLAUDE_CONFIG_DIR` outside the repository) and throwaway repositories. Every entry in the record of runs gives the date, the machine, the Claude Code, gh and Node versions, the items run, and the result.
